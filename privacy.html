Family Calendar Privacy Policy

Family Calendar is a private application used to display Google Calendar events on a personal household dashboard.

Google Data Accessed

Family Calendar requests read-only access to Google Calendar. It accesses calendar event information such as event titles, dates, and times solely for displaying those events on the family calendar dashboard.

How Data Is Used

Google Calendar data is used only to provide the calendar display functionality. The application does not modify Google Calendar data.

Data Storage

Authentication credentials are stored locally on the private Raspberry Pi running the application. Calendar event information is retrieved as needed for display.

Data Sharing

Google user data is not sold, shared with advertisers, or provided to third parties.

Contact

Questions regarding this application or privacy policy can be directed to the contact information provided on smgillen.com.
